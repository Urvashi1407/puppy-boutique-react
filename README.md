# PupNest React Frontend

## Run locally
1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. In the terminal, run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Customize before publishing
- In `src/App.jsx`, replace `0000000000` in `waNumber` with your WhatsApp number, including country code but without `+`.
- Replace `hello@example.com` and the sample customer review with your real details.
- Puppy photos currently load from Unsplash and need an internet connection.
- Only publish claims about health checks, vaccinations, availability, or delivery that you can verify.

## Create a production build
Run `npm run build`. Vite writes the deployable site to `dist/`.
